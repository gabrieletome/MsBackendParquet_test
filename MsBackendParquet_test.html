Test MzR vs Parquet

In this section I will compere the standard method against MsBackendParquet

File_1

Open file with Spectra().

microbenchmark(
    sps_mzr <- Spectra(file_1, source = MsBackendMzR()),

Next I compare the extraction of the peaks using peaksData(). The parquet method seems faster respect MzR. The function expect_equal() confirm that the results are the same.
